# HomeLibrary

Тестовое приложение для работы с домашней библиотекой.

## Стек

* ASP.NET Core MVC
* .NET 10
* MS SQL Server
* ADO.NET / Microsoft.Data.SqlClient
* Stored Procedures
* XML / XQuery
* Bootstrap
* TinyMCE

## Реализовано

* просмотр списка и карточки книг;
* создание, редактирование и удаление книг;
* работа с БД через хранимые процедуры;
* загрузка оглавления из XML-файла;
* редактирование оглавления через HTML-редактор;
* отображение XML-оглавления;
* примеры выборки и поиска данных в XML.

## Запуск

1. Создать БД `HomeLibrary`.
2. Проверить строку подключения `HomeLibrary` в `appsettings.json`.
3. Запустить проект `WebApplicationMVC`.
